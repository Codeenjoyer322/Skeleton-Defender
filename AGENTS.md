# Работа с Skeleton Defender

- По указанию владельца проект хранится в приватном репозитории. При создании нового удалённого репозитория для этого проекта явно выбирать Private. Не делать репозиторий или игровые материалы публичными без отдельного явного указания владельца.
- Основная рабочая папка содержит Unity-проект. Сохранять пользовательские изменения и существующую экипировку/сохранения; GitHub служит для истории исходников, а полный бэкап хранится отдельно.
- Соблюдать `.gitignore`: не добавлять принудительно `Library`, `Builds`, `work`, `Logs`, `Temp` и `UserSettings` в историю исходников. Готовые таблицы в `outputs` и документы в `docs` являются материалами проекта.
- После изменений игровых правил обновлять соответствующие описания и таблицы баланса. Правила и цифры брать из запросов пользователя и текущего `Assets/Resources/balance.json`.
- Состояние и способы запуска описаны в `README.md`. Дополнительные команды проверок и сборки также указаны там.
