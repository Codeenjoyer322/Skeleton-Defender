# Редактируемая графика Skeleton Defender

Эта папка хранится вместе с исходниками игры в **приватном** репозитории владельца.

- `NeonGothic/exports/actors` — принятые направленные анимации: Aseprite, GIF, PNG и статичные превью.
- `NeonGothic/source/environment` и `source/icons` — редактируемые окружение и иконки.
- `NeonGothic/v081` — исправления посоха, новые олени, башни и карта версии 0.8.1.
- Остальные каталоги повторяют относительные пути ранее принятых анимаций из `Testnew2`.
- `source-index.json` — состав сохранённого набора, размеры и SHA-256 файлов.

Игра загружает готовые ресурсы из `Assets/Resources`; эта папка предназначена для редактирования и восстановления графики. Сценарий `tools/archive-art-sources.py` обновляет копию по принятым материалам рабочего стола. Для разработки на другом компьютере исходная папка рабочего стола не нужна: игровые ресурсы и редактируемые копии уже находятся в репозитории.

Сборки и кэш Unity остаются вне Git согласно `.gitignore`. Запросы с изображениями к PixelLab, настройки аккаунта, ключи API и отклонённые варианты не являются частью этого набора; рабочий полный архив хранится отдельно на компьютере владельца.
