## Новые материалы

- Священный олень: восемь самостоятельных ракурсов и восемь циклов бега по 16 кадров. Белая шерсть, золотые ветвистые рога, тонкие копыта. Базовый цикл 0,80 с; игровое замедление воспроизведения применяется отдельно.
- Башни: девять отдельных основ 144×192, три семейства по три уровня. Общая опора в пикселях (72,182), масштаб рисунков сохранён. Позиции ядра огня/льда измерены на изображениях.
- Башенный эльф: отдельные ожидание и выстрел в восьми направлениях. Уровни I/II используют одного, III — двух. Фигурки и снаряды рисуются независимо от архитектуры. Натяжение, выпуск и возврат составляют 0,50 с; выпуск происходит через 0,20 с.
- Четыре походки Цирцеи: посох проходит через настоящую ладонь, кристалл и сокеты исправлены по кадрам; лицо, глаза, подол и сапоги сохранены.
- Карта и меню: основу PixelLab довёл главный агент в Aseprite; локальные исправления травы, ворот и старых площадок наложены через точные маски. В меню восстановлена обычная мостовая на месте знаков.

## Импорт и проверка

`source/prepare_delivery.py` читает только принятые `review/manifests/*-qa.json`, вызывает нативный Aseprite и проверяет сохранность каждого видимого пикселя. PNG для игры обрезаются по единому объединённому прямоугольнику всего клипа; опоры и сокеты сдвигаются на тот же вектор. Полные GIF, первый кадр и редактируемые Aseprite сохраняют исходный холст.

`source/merge_v081.py` заменяет только соответствующие записи в копии предыдущего каталога. Остальные персонажи, направления и способности остаются прежними. Существующие изображения не отражаются для подмены новых ракурсов.

`source/finalize_tower_catalog.py` проверяет точное сохранение пикселей архитектуры и непрозрачность магических ядер. Канонические сокеты лучников выводятся из принятого восточного выстрела; в игре используется фактическое направление отдельной фигурки.

Галерея проверяется по существованию PNG/GIF/Aseprite/still и выполнением настоящего JavaScript фильтров, пагинации, остановки анимаций и увеличения. Результаты находятся в `review/*verification.json`. Игровые Unity-проверки и сборки выполняются отдельно главным агентом и агентом модели; эти проверки изображений не заменяют прохождение уровня.
