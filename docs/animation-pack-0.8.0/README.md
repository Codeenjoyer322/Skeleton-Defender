# Персонажи: PixelLab → Aseprite → Unity

Новый набор использует отдельные изображения восьми ракурсов. Повороты тела в игре и зеркальные копии бокового вида для подмены недостающих направлений не используются. Ахилл и Цирцея сохраняют ранее одобренную внешность; новые фоновые цвета не меняют экипировку героев.

## Где лежат материалы

Пути ниже отсчитываются от папки `C:/Users/Life/Desktop/Testnew2/NeonGothic`. В Unity-проекте папка `docs/animation-pack-0.8.0` хранит копии отчётов и провенанса; игровые PNG и каталог лежат в `Assets/Resources/AnimationPack`.

- `raw/actors`: исходные ответы PixelLab, запросы без ключа API и полученные кадры. Исходная графика сохранена.
- `source/actors`: проверенные кадры после правок в Aseprite. Рядом сохранены нативные исходники и воспроизводимые Lua-скрипты исправлений.
- `review/manifests/*qa.json`: только принятые после просмотра последовательности, их направления, длительности, точки оружия и кадры контакта.
- `review/accepted-manifest.json`: объединение принятых частей. Число файлов включает дополнительные стойки и намеренные повторные ссылки на одинаковые тела.
- `review/coverage-progress.json`: покрытие 344 обязательных направлений действий; именно этот отчёт отличает готовый пакет от промежуточного.
- `exports/actors`: для каждого действия и направления — `.aseprite`, анимированный `.gif`, неподвижный `still.png` полного холста и компактный игровой атлас `animation.png`.
- `exports/provenance.json`: исходные файлы, SHA-256, причины нативных исправлений и параметры обрезки.
- `exports/verification.json`: количество проверенных кадров и объём несжатых игровых текстур. Это проверка экспорта, а не заявление о прохождении уровня вручную.

## Что именно исправлялось

PixelLab создавал исходные ракурсы и движения. В Aseprite удалялись случайные знаки над головами, лишнее оружие, отделённые вспышки и ошибочные развороты. Если отдельное движение не читалось, сохранялось настоящее тело нужного ракурса и исправлялась рабочая рука, клинок или движение головы. Отвергнутое сырьё не включается в каталог принятых анимаций.

Направления ползущего скелета были сопоставлены с фактическими ракурсами: исходные подписи оказались смещены на один сектор. Этот перенос явно записан в `sourceDirectionLabel`; изображение при этом не поворачивалось. Обычный скелет и скелет после разрушения саркофага используют одинаковую одобренную форму тела через явные ссылки `aliasOf`.

Для жабы нужны восемь стоек: она не атакует и не ходит по действующим правилам игры. Неиспользуемые боевые действия для неё не добавлялись. Ранее одобренные смерти, получение урона и специальные приёмы героев остаются отдельным набором; новый пакет расширяет прежде всего ходьбу и обычные атаки.

## Регистрация и память

Все кадры одного движения размещаются на общем холсте с постоянным смещением относительно исходной стойки. Подпрыгивание при ходьбе сохраняется. Для игрового атласа обрезается только общая прозрачная рамка всей последовательности; все кадры получают одинаковый прямоугольник обрезки. Опорная точка, центр попадания, точки оружия и события смещаются на ту же величину.

`prepare_delivery.py` сравнивает каждый видимый пиксель исходного нативного кадра с результатом обрезки, проверяет непустые кадры, длительности, границы событий и отсутствие потери пикселей. Изображения читаются Python только для анализа; растровые изменения и экспорт выполняет Aseprite. Unity получает PNG без сглаживания и уменьшения разрешения. Одинаковые атласы хранятся один раз по SHA-256.

## Расходы

У этой работы отдельные журналы: `actors-ledger.json` для персонажей и `raw/environment/*/state.json` для окружения. Для первой фазы общий предел составлял 1000 оставшихся генераций: на персонажей не больше 830, на окружение 120 и резерв 50. Платные запросы выполняет одна очередь с учётом активных серверных задач. Неопределённый результат запроса нельзя автоматически повторять. Ключ API не включён в этот набор.

Очередь завершилась 7 сентября 2026 года. Официальный баланс изменился с 1115,9 до 283,9: потрачено 832 генерации, включая 712 на персонажей и 120 на окружение. Предел 1000 соблюдён. Подробная сверка и различие между возвращённой стоимостью отдельных задач и общей разницей баланса находятся в `exports/budget-verification.json`.

После этого владелец разрешил при необходимости потратить ещё не больше 283 генераций на конкретные улучшения качества. Это отдельная необязательная фаза: общий разрешённый расход теперь не больше 1115, без покупок. В момент записи разрешения новых платных запросов не было, фактический расход оставался 832; история обеих фаз сохранена в `authorizationPhases` журнала.

Финальный экспорт содержит 488 принятых клипов и покрывает все 344 обязательных направления действий. Дополнительные записи — стойки и явные повторные ссылки на одинаковые формы тела. Результаты Unity-проверок и сборок записываются отдельно командой проекта; сам экспорт не подменяет эти проверки.
